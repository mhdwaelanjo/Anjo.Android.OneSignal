# Anjo.Android.OneSignal.Notifications

---------------------------------
OneSignal Notifications SDK for .NET for Android (formerly Xamarin.Android) Binding Library - Wael Anjo
---------------------------------

[![NuGet](https://buildstats.info/nuget/Anjo.Android.OneSignal.Notifications)](https://www.nuget.org/packages/Anjo.Android.OneSignal.Notifications/)

OneSignal is a free email, sms, push notification, and in-app message service for mobile apps. This plugin makes it easy to integrate your native Android or Amazon app with OneSignal.
Learn more at https://onesignal.com/

---------------------------------
### How To Use

Getting Started: https://documentation.onesignal.com/docs
